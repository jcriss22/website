# jamescrissman.com

Personal academic/industry site. Plain HTML/CSS, no build step, hosted on GitHub Pages.

## Structure
- `/` — home
- `/cv/` — unified CV
- `/research/` — project write-ups
- `/photography/` — portfolio
- `/contact/` — contact info and links

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static server, e.g.:

```
npx serve .
```
